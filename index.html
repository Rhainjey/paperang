Printing setup
  • Epson L3210: install the Epson driver, load A4 paper, and in the print dialog choose the L3210 with the same paper size, Margins: None, Scale: 100%, and a photo or high quality mode. The L3210 prints up to 215.9 mm wide and 1200 mm long, so A3 sheets cannot be used.
  • Long sheet: add a custom 210 × 420 mm paper size in the Epson driver (Printing preferences → Custom) and choose it in the print dialog.
  • Thermal TP870: use the waybill or receipt preset and set the matching paper size in its driver.
  • For the kiosk, start Chrome with the --kiosk-printing flag so it prints straight to the default printer without the dialog.
