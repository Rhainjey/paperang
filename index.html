How connecting works
  • Use Chrome or Edge (desktop/Android) over HTTPS. iPhone Safari has no Bluetooth/Serial API.
  • Connect (Bluetooth) scans for a device named “Paperang…” using Web Bluetooth (BLE). Don't pair it in OS settings first.
  • If your P1S only speaks classic Bluetooth, pair it in your OS first, then use Connect (paired / Serial) and choose its COM / serial port.
  • Protocol is based on the reverse-engineered projects: tinyprinter/python-paperang (GitHub) and the Web Bluetooth Paperang P1 interface. It is untested on a real P1S, so check the log if nothing prints.
